# KittenRushDownload

KittenRush 다운로드 랜딩 (GitHub Pages). QR 코드가 이 페이지를 가리키고, 플랫폼별 스토어로 즉시 redirect 한다.

- Android → Play Store
- iOS/iPadOS → App Store
- 그 외 (desktop 등) → Steam

`location.replace` 라 히스토리에 안 남음 (back 으로 재진입 불가). 스토어 링크는 `index.html` 상단 상수 (Play `com.kittenlab.kittenrush` / App Store `id6804417576` / Steam `5174900`).
